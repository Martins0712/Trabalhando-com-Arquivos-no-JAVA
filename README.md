# 📂 Manipulação de Arquivos em Java

Repositório dedicado ao estudo e desenvolvimento de soluções para leitura e manipulação de arquivos utilizando a linguagem Java.

## 🎯 Objetivo
O foco principal deste projeto é explorar os conceitos de entrada e saída de dados (I/O) do ecossistema Java, praticando a interação direta com o sistema de arquivos de forma segura, performática e com tratamento de exceções.
